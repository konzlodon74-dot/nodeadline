## How it works

`main.py` holds a single hand-written excuse line and validates it before writing:
it must be non-empty, contain no newline or carriage return, and be 1–200
characters long. It then writes exactly that line to `/output/entry.txt`
with no trailing newline, using only the Python standard library.
